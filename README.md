# بوابة بيانات الطالبات

منصة ويب عربية (RTL) للبحث عن بيانات الطالبات وإدارتها، مبنية بـ Next.js وTypeScript وTailwind CSS مع Supabase للبيانات والمصادقة.

## المميزات

- صفحة رئيسية للبحث الآمن برقم الهوية فقط (بدون تسجيل دخول).
- لوحة مشرف محمية بتسجيل دخول Supabase Auth.
- إضافة وتعديل وحذف السجلات مع تأكيد الحذف.
- حماية RLS: الزوار لا يستطيعون قراءة جدول `students` مباشرة.
- البحث العام يتم عبر دالة آمنة تعيد الطالبة المطابقة فقط.
- حماية من الطلبات المتكررة (10 محاولات بحث في الدقيقة لكل عنوان IP).
- دعم الأرقام العربية والإنجليزية مع توحيدها قبل المطابقة.

## التشغيل محلياً على Windows

1. ثبّتي Node.js (إصدار 18 أو أحدث) من nodejs.org.
2. افتحي موجه الأوامر داخل مجلد المشروع:
   ```
   npm install
   ```
3. انسخي `.env.example` إلى `.env.local` واملئي القيم:
   ```
   copy .env.example .env.local
   ```
4. شغّلي المشروع:
   ```
   npm run dev
   ```
5. افتحي المتصفح على `http://localhost:3000`.

## إعداد Supabase

1. أنشئي مشروعاً جديداً على supabase.com.
2. من القائمة الجانبية افتحي **SQL Editor** وشغّلي محتوى ملف `supabase/schema.sql` كاملًا.
3. من **Project Settings > API** انسخي:
   - Project URL → ضعيه في `NEXT_PUBLIC_SUPABASE_URL`
   - anon public key → ضعيه في `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
4. أنشئي حساب المشرف من **Authentication > Users > Add user** (بريد إلكتروني وكلمة مرور).
5. لا تستخدمي `service_role key` في المشروع، فقط مفتاح `anon`.

## متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | رابط مشروع Supabase |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | مفتاح anon العام |

## النشر على Vercel

1. ارفعي المشروع إلى مستودع GitHub.
2. من vercel.com اختاري **New Project** واستوردي المستودع.
3. في صفحة الإعدادات أضيفي متغيرات البيئة نفسها الموجودة في `.env.local`.
4. اضغطي **Deploy**، وبعدها تحصلين على رابط عام.

## التحديث بعد التعديل

- بعد أي تعديل، نفّذي `git add .` ثم `git commit -m "وصف التعديل"` ثم `git push`.
- Vercel يعيد النشر تلقائياً عند الدفع إلى الفرع الرئيسي.

## ملاحظات الأمان

- لا تضع كلمة المرور أو `service_role key` في الكود أو في GitHub.
- ملف `.env.local` مستثنى من Git عبر `.gitignore`.
- سياسة RLS تمنع الزوار من قراءة أو تعديل أو حذف السجلات، وجميع عمليات الإدارة تتطلب مصادقة.
- لا تُسجَّل أرقام الهوية أو بيانات الطالبات في سجلات الأخطاء.
